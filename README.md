# Workplace AI Companion

Build a modern, responsive web application called “AI Workplace Productivity Assistant”.

This is a professional AI productivity tool designed to help employees, graduates, administrators, managers and other professionals automate common workplace tasks.

IMPORTANT:

- Build the application as a functional prototype.

- Use a clean, modern SaaS design.

- Do not overcomplicate the architecture.

- Prioritize functionality, usability and responsiveness.

- Make the application suitable for a professional project demonstration.

APPLICATION LAYOUT:

Create a dashboard-style application with:

1. A left sidebar navigation.

2. A top navigation/header.

3. A main content area.

4. Responsive design for desktop, tablet and mobile.

5. Card-based components.

6. Clear buttons and form controls.

7. Loading states for AI operations.

8. Error states where appropriate.

9. Empty states where appropriate.

SIDEBAR NAVIGATION:

Include:

- Dashboard

- Smart Email Generator

- Meeting Notes Summarizer

- AI Task Planner

- AI Research Assistant

- AI Workplace Chatbot

- About / Responsible AI

DASHBOARD:

Create a professional dashboard showing:

- Welcome message

- Short description of the assistant

- Five productivity tools as cards

- Quick action buttons

- Recent activity section

- Productivity tips section

FEATURES:

1. SMART EMAIL GENERATOR

Create a form with:

- Audience dropdown:

  Client

  Manager

  Team

  Colleague

  Other

- Tone dropdown:

  Formal

  Professional

  Friendly

  Persuasive

- Email purpose

- Key information/context

- Desired outcome

Include a “Generate Email” button.

Display the generated result with:

- Subject

- Email body

- Copy button

- Regenerate button

2. MEETING NOTES SUMMARIZER

Create a large text area where users can paste meeting notes.

Include a “Summarize Meeting” button.

The result should contain:

- Meeting Summary

- Key Discussion Points

- Decisions Made

- Action Items

- Responsible Person

- Deadlines

3. AI TASK PLANNER

Allow users to enter multiple tasks.

Each task should support:

- Task name

- Description

- Deadline

- Priority

Include a “Generate Plan” button.

The AI-generated result should organize tasks according to:

- Urgent and Important

- Important but Not Urgent

- Urgent but Less Important

- Low Priority

Generate a suggested daily schedule.

4. AI RESEARCH ASSISTANT

Create an input area where users can enter a research question or topic.

Include:

- Research topic/question

- Desired level:

  Simple

  Intermediate

  Detailed

Include a “Research” button.

Display:

- Overview

- Key Insights

- Important Points

- Recommendations

- Questions for Further Research

5. AI WORKPLACE CHATBOT

Create an interactive chatbot interface.

The chatbot should:

- Accept user questions

- Display user messages

- Display AI responses

- Maintain conversation history during the session

- Show loading state while generating responses

Example questions:

- “Help me prepare for a meeting.”

- “Write a professional email to my manager.”

- “Help me prioritize my tasks.”

- “Summarize this information.”

- “Give me tips for managing my workload.”

RESPONSIBLE AI:

Include a clearly visible disclaimer:

“AI-generated content may require human review.”

Also explain that:

- AI may occasionally produce inaccurate information.

- Users should verify important information.

- Users should not rely on AI-generated content without review.

- Users should avoid entering unnecessary confidential or sensitive information.

DESIGN:

Use a modern professional SaaS design.

The interface should feel:

- Clean

- Minimal

- Professional

- Easy to navigate

- Suitable for a workplace environment

Use consistent typography, spacing, cards, buttons and form controls.

Make all pages responsive.

IMPORTANT:

Create reusable components where appropriate.

Do not create unnecessary features that are outside the project requirements.
